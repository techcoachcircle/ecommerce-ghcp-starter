# API Gateway

## Description
The API Gateway acts as the single entry point for all client requests. It routes, authenticates, and authorizes requests to the appropriate backend microservices, and handles cross-cutting concerns such as rate limiting and logging.

## Communicates With
- Web Frontend (React)
- Admin Frontend (Angular)
- Authentication Service
- User Service
- Product Catalog Service
- Inventory Service
- Cart Service
- Order Service
- Payment Service
- Promotion Service
- Review & Rating Service
- Analytics & Reporting Service
- Customer Support Service
- Notification Service
- Shipping & Logistics Service
- Tax & Compliance Service
- Fraud Detection Service
