# ErrorResponse

## Description
The `ErrorResponse` is a TypeScript interface or class that defines the structure of error responses returned by the backend API. It is used to provide error details to the UI for display and handling.

## Attributes
| Attribute | Data Type | Description                                 |
|-----------|-----------|---------------------------------------------|
| error     | string    | Error code or type                          |
| message   | string    | Human-readable error message                 |
