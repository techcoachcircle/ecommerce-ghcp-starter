# UserProfile

## Description
The `UserProfile` is a TypeScript interface or class that defines the structure of a user's profile information. It is used as a nested object within `UserResponse` and contains personal and contact details for the user.

## Attributes
| Attribute   | Data Type | Description                                 |
|-------------|-----------|---------------------------------------------|
| name        | string    | Full name of the user                       |
| address     | string    | Shipping/billing address                    |
| phone       | string    | Contact phone number                        |
| avatarUrl   | string    | URL to the user's profile picture           |
| dateOfBirth | string    | User's date of birth (optional)             |
