# UserProfile

## Description
Encapsulates the profile information of a user, including personal and contact details. Used as part of the `UserResponse` and as a domain entity.

## Attributes
| Name        | Type   | Description                        |
|-------------|--------|------------------------------------|
| Name        | string | Full name of the user              |
| Address     | string | User's address                     |
| Phone       | string | User's phone number                |
| AvatarUrl   | string | URL to the user's avatar image     |
| DateOfBirth | Date   | User's date of birth               |

|------|--------|-------------|--------|-------------|
| None |        |             |        |             |

## Class Dependencies
None (used as a value object in other classes).
