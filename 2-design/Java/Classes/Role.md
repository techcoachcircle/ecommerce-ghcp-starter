# Role

## Description
`Role` is an enumeration (enum) representing the possible roles a user can have in the ShopSphere platform. It is used for role-based access control (RBAC) and authorization.

## Attributes
| Attribute | Data Type | Description |
|-----------|-----------|-------------|
| (enum values) | String | Possible values: CUSTOMER, SELLER, ADMIN |

## Methods
| Method Signature         | Input(s) | Return Type | Access | Description |
|-------------------------|----------|-------------|--------|-------------|
| (enum methods)          | -        | -           | public | Standard enum methods (valueOf, values, etc.) |

## Class Dependencies
- Used by the `User` entity and throughout the authentication/authorization system.
